# SupportMind AI

## Project Overview

SupportMind AI is an AI-powered customer support platform built using Spring Boot, Spring AI, React, MySQL, and ChromaDB.

The platform enables customers to:

- Track orders
- Check refund status
- Create support tickets
- Ask questions about company policies
- Receive intelligent AI-assisted support

Unlike traditional chatbots, SupportMind AI combines:

- Business data from MySQL
- Company knowledge from a vector database
- AI reasoning through Spring AI
- Tool Calling for automated actions

The project is designed to simulate a real-world enterprise customer support system.
